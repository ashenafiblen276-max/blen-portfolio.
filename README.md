# Blen Ashenafi — Personal Portfolio

A responsive personal portfolio built with PHP, MySQL, HTML, and CSS.

## Files
- `index.php` — portfolio and contact form
- `message.php` — inbox for saved contact messages
- `style.css` — responsive design and animations
- `myphoto.jpg.jpg` — current profile image

## Run locally
1. Put this folder inside XAMPP's `htdocs`.
2. Start Apache and MySQL.
3. Open `http://localhost/folder-name/index.php`.

The contact form creates the `blen_portfolio` database and `messages` table automatically when MySQL is running.

**Note:** GitHub Pages does not run PHP. Use a PHP-capable host for the contact form and inbox.
